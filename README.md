# 校園公告一鍵發布小幫手（Chrome 插件＋公文自動更名 Skill）

把「公文 → 學校網站公告」這件事從十幾個手動步驟縮成約 30 秒。

- **Skill**：把公文系統下載的英文亂碼檔名，自動更名成「發文字號＿函＿主旨」的清楚中文檔名。
- **Chrome 插件**：在學校公告網頁一鍵填好標題、分類、公開狀態，並把公文與附件排成可點擊下載的超連結清單。

> 本專案針對臺中市校園資訊系統公告網（`school.tc.edu.tw/open-news/...`）。
> 其他縣市請修改 `extension/manifest.json` 的 `matches` 與 `content.js` 的欄位選擇器。

## 運作方式

```
公文系統下載 PDF＋附件到暫存資料夾
   ↓ AI 或手動執行 rename_doc.py（解析 PDF 取得發文字號與主旨）
檔名變成「發文字號＿函＿主旨.pdf」「發文字號＿附件1＿主旨.ext」
   ↓ 在已登入的公告網頁新增訊息、上傳檔案
點右上角面板「一鍵完成」→ 自動填標題、分類、公開、附件連結清單
   ↓ 點「儲存並發布」
```

## 安裝

### Chrome 插件
1. 網址列輸入 `chrome://extensions/`，開啟右上角「開發人員模式」。
2. 「載入未封裝項目」→ 選擇本專案的 `extension` 資料夾。
3. 到公告網頁按 `F5`，右上角會出現操作面板。
4. 想改勾選的分類，編輯 `extension/content.js` 最上方的 `CATEGORY_KEYWORD`（預設 `教務處`）。

### 公文更名腳本
```bash
pip install -r requirements.txt
python skill/scripts/rename_doc.py            # 預設處理「下載/暫存」資料夾
python skill/scripts/rename_doc.py D:\公文暫存  # 或指定資料夾
```
`skill/SKILL.md` 是給 AI 助理（Claude Code、Antigravity 等）用的流程說明，
放進 AI 的 skills 資料夾後，對 AI 說「幫我把暫存區公文改名」即可。

## 設計重點
- **AI 做不確定的事，插件做固定的事**：解析公文、判斷主旨需要理解內容，交給 Skill；
  網頁表單填寫每次都一樣，交給插件更快更穩。
- **不碰帳號密碼**：插件只在你已登入的瀏覽器內操作，不儲存、不傳送任何帳密。
- **沒有對外連線**：整個插件約 5KB，只在公告網站網址範圍內執行，可一次看完。

## 注意事項
- 公文與附件常含個資，**暫存資料夾絕對不要上傳**（`.gitignore` 已擋）。
- 發布前請自行確認標題與附件是否適合公開。
- 網站改版時，欄位選擇器可能需要調整。
